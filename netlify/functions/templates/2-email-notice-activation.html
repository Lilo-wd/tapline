Pour que votre carte Tapline collecte vos premiers avis dès sa réception, voici le guide complet de mise en service, étape par étape.

1. Positionnez le haut de votre téléphone sur la carte NFC.
2. Cliquez sur la notification que vous avez reçue :

3. Vous atterrissez sur cette page sur laquelle vous allez pouvoir créer votre compte :

4. Une fois le compte créé, ouvrez une autre page Google for developers et cherchez votre boutique / point de vente : developers.google.com/.../places-placeid-finder

5. Lorsque vous avez trouvé votre boutique à son adresse précise, copiez la « Place ID » :

6. Rendez-vous sur ReviewSense, un générateur de lien qui redirige vers une page d'avis Google, puis collez la « Place ID » : reviewsense.ai/google-review-link-generator

7. Un lien vers votre page d'avis Google est généré, copiez-le :

8. Revenez sur la première page, collez le lien généré sur ReviewSense et ajoutez une description pour ne pas confondre vos cartes entre elles :

9. Félicitations, votre carte est configurée ! Cliquez sur « Consultez et gérez les cartes » pour accéder à l'interface où se trouvent l'ensemble de vos cartes configurées :

10. Sur cette interface accessible uniquement avec votre compte, vous pouvez modifier le lien de chaque carte autant de fois que vous le souhaitez.
